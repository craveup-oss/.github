# Crave Open Source

Restaurant-native commerce infrastructure for developers building ordering, loyalty, integrations, and guest experiences.

## Flagship project

### [Crave Orders Manager](https://github.com/craveup-oss/crave-orders-manager)

An open-source, tablet-first order and fulfillment console for restaurant teams. Explore live and
completed queues, ready-time promises, order actions, item availability, and fulfillment controls
in a credential-free offline demo built with Expo and React Native.

```bash
git clone https://github.com/craveup-oss/crave-orders-manager.git
cd crave-orders-manager
npm ci
npm run demo
```
