# Crave Open Source

Restaurant-native commerce infrastructure for developers building ordering, loyalty, integrations, and guest experiences.

## Build with Crave

- [Developer Platform](https://developer.craveup.com) — tools and workflows for building restaurant commerce.
- [Documentation](https://docs.craveup.com) — APIs, SDKs, integration guides, and platform concepts.
- [Crave](https://craveup.com) — guest experiences and restaurant operations infrastructure.

Our public projects favor explicit contracts, reproducible releases, secure defaults, and merchant-controlled data access.
